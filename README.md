## Projects

### OpenSystem

A modular adversarial reasoning and testing engine built in Python. It models
target systems, forms hypotheses about weaknesses, and runs structured test
campaigns backed by a persistent knowledge store.

`Python` `SQLite` `pytest`

[Repository](https://github.com/perseus-lelush/opensystem)

### Hierarchy Class

A gamified academic tracking platform for students, teachers, and school
administrators. Real grades drive a tiered rank system, with grade approval
workflows, messaging, and habit tracking built on verified school data.

`Next.js` `TypeScript` `Supabase`

[Repository](https://github.com/perseus-lelush/hierarchy_class)

### Portalyx

A web-based school management portal covering student registration,
enrollment, class and subject management, grade encoding, grade viewing,
and academic records, with first-party session authentication.

`Nuxt` `Vue` `TypeScript` `PostgreSQL` `Drizzle ORM`

[Repository](https://github.com/perseus-lelush/portalyx)

### School Council Voting System

A web application for school student council elections with anonymous
ballots. Votes carry no voter identity, and administrators only see
aggregate results.

`Next.js` `TypeScript` `PostgreSQL` `Drizzle ORM`

[Repository](https://github.com/perseus-lelush/school_council_voting_system)
